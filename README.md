### Practice 1.

Найти вероятность того, что среди этих карт:
а) окажутся представители всех мастей;
б) будет ровно 5 карт одной масти.

**21.** На шахматную доску поставили наугад белую и черную ладьи.

**29.** Двое человек договорились встретиться между 12:00 и 13:00.
